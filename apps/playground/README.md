# @shanku/playground 0.1.6

The full Shanku window built from `@shanku/ui`, with sample data for one selected column. Use it to review the UI in Paper and Ink and to try the components.

```bash
npm run dev -w @shanku/playground
```

Working: theme switch (follow OS → Paper → Ink), ribbon tools toggle, editable width and depth (150–3000 mm) that update the volume and BOQ, project browser opens views as tabs, bottom panel toggle (Ctrl + ` or Ctrl + Shift + `), Ctrl K focuses search, a console that echoes commands.

Placeholder: the 3D view is a static isometric drawing (three.js arrives with the app engine), and the console does not run Python yet (Pyodide arrives later).
